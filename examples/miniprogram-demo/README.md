# OmniCrop 微信小程序完整演示项目 (Miniprogram Demo)

这是一个基于 `omni-crop/weixin` 打造的**开箱即用、零外部构建依赖**的完整微信小程序项目，可直接通过**微信开发者工具**导入运行。页面 `index.json` 直接通过 `"omni-crop": "omni-crop/weixin"` 导入组件。

---

## 🚀 如何运行

1. 打开 **微信开发者工具**。
2. 点击 **导入项目**。
3. 目录选择：`/Users/zfkc/Desktop/04-AI/omni-crop/examples/miniprogram-demo`。
4. AppID 选择：**测试号**（或填入自己的微信小程序 AppID）。
5. 模式选择：**小程序**。
6. 点击确定导入，即可在模拟器中体验 60 FPS 流畅裁剪！

---

## ✨ 演示包含的核心功能

1. **60 FPS WXS 跟手交互**：
   - 单指拖拽平移图片
   - 双指捏合平滑缩放（Zoom）
   - 双指旋转图片角度
2. **多比例快速切换**：
   - `1:1`（头像常用）
   - `4:3`（经典照片）
   - `16:9`（横幅 / 视频封面）
   - `自由`（自由比例自适应）
3. **裁剪形状切换**：
   - 矩形（Rect）
   - 圆形头像（Round Mask，自动适配圆形遮罩）
4. **几何变换命令式操作**：
   - 🔄 **旋转 90°**（步进旋转）
   - ↔️ **水平翻转**（Flip Horizontal）
   - ↕️ **垂直翻转**（Flip Vertical）
   - ↩️ **重置**（恢复初始位置与比例）
5. **图片输入源**：
   - 本地预置的高清色彩渐变网格图 (`/assets/sample.png`)
   - 手机本地相册选取 / 拍照 (`wx.chooseMedia`)
6. **Canvas 2D 高清离屏导出**：
   - 点击「导出高质量裁剪图」
   - 采用微信新版 Canvas 2D 进行硬件加速离屏渲染
   - 支持 2 倍物理像素高清抗锯齿
   - 弹出预览弹窗并支持一键「保存到系统相册 (`wx.saveImageToPhotosAlbum`)」
